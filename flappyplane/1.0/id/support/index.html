Flappy Plane: Sky Hangar · Pengembang: Anonymous Play

Ada pertanyaan, laporan bug, atau ide? Kirim email ke help.blizzard269@dralias.com dan sertakan model perangkat serta versi aplikasi.

Bagaimana cara terbang?

Ketuk layar untuk menaikkan pesawat; di antara ketukan, pesawat melayang turun. Terbanglah melewati celah di antara tebing. Satu tabrakan mengakhiri penerbangan, kecuali jika perisai atau nyawa cadangan melindungi Anda.

Bagaimana cara mendapatkan pesawat baru?

Tangkap paket saat terbang. Anda bisa menemukan paling banyak satu pesawat baru per penerbangan; pilih pesawat itu di hanggar sebelum lepas landas berikutnya.

Apakah progres saya tersimpan?

Ya, di perangkat Anda. Progres akan terhapus jika Anda menghapus data aplikasi atau mencopot pemasangannya.

Apakah game ini memerlukan internet?

Tidak. Game ini dapat dimainkan offline dan tidak memiliki iklan maupun pembelian dalam aplikasi.
