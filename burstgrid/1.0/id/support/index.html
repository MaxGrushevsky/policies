Dukungan

Burst Grid · Pengembang: Anonymous Play

Ada pertanyaan, laporan bug, atau ide? Kirim email ke help.blizzard269@dralias.com dan sertakan model perangkat serta versi aplikasi.

Bagaimana cara bermain?

Seret satu balok dari baki ke grid 8×8. Baris dan kolom yang penuh akan hilang. Jika tidak ada balok tersisa yang muat, permainan berakhir.

Apa itu bonus?

Petunjuk, Urungkan, dan Acak membantu saat Anda buntu. Stoknya disimpan di perangkat Anda.

Apakah progres saya tersimpan?

Ya, di perangkat Anda. Progres akan terhapus jika Anda menghapus data aplikasi atau mencopot pemasangannya.

Apakah game ini memerlukan internet?

Tidak. Game ini dapat dimainkan offline dan tidak memiliki iklan maupun pembelian dalam aplikasi.
