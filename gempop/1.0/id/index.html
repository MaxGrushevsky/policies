Kebijakan Privasi

Gem Pop

Berlaku sejak 2 Oktober 2026.

Gem Pop (“game”) adalah game seluler dari Tenvar (“kami”).

Data yang dikumpulkan oleh game itu sendiri. Tidak ada. Progres Anda (level, bintang, koin, energi, bahasa, serta pengaturan suara dan getaran) hanya disimpan di perangkat Anda dan tidak pernah dikirim ke mana pun. Game ini tidak memiliki pendaftaran atau akun, dan kami tidak menjual atau membagikan data Anda.

Iklan. Game ini menampilkan iklan dari Google AdMob: video berhadiah opsional dan iklan interstisial di antara level. Untuk menayangkan dan mengukur iklan, Google dapat mengumpulkan data perangkat seperti ID iklan, alamat IP, model perangkat, versi sistem operasi, perkiraan lokasi berdasarkan IP, dan data interaksi iklan. Data dikirim dalam bentuk terenkripsi. Cara Google menggunakan data ini: policies.google.com/technologies/partner-sites.

Persetujuan. Di wilayah yang mewajibkannya (EEA, Inggris, dan Swiss), formulir persetujuan Google ditampilkan saat game pertama kali dibuka. Anda dapat mengubah pilihan kapan saja: Pengaturan dalam game → Privasi iklan. Anda juga dapat menonaktifkan personalisasi iklan di setelan Android: Setelan → Google → Iklan.

Menghapus data. Semua data game tetap berada di perangkat Anda — hapus data aplikasi atau copot pemasangan game untuk menghapusnya. Anda dapat menyetel ulang atau menghapus ID iklan di setelan Android.

Anak-anak. Game ini tidak ditujukan untuk anak di bawah 13 tahun, dan kami tidak dengan sengaja mengumpulkan data mereka.

Perubahan. Kami dapat memperbarui kebijakan ini. Versi baru dipublikasikan di tautan yang sama.
