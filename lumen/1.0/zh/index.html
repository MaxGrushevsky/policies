隐私政策

Lumen: Lights Out · 开发者: Anonymous Play

生效日期：2026年10月13日。

本政策适用于不含广告和使用情况分析的游戏版本，以及您联系支持团队时提供的信息。

游戏中的数据

游戏无需注册或登录账号。我们不会从您的设备收集或传输个人数据、广告标识符、位置信息、联系人或游戏使用情况数据。游戏不包含广告或分析 SDK、应用内购买、聊天功能或用户发布的内容。

游戏进度与设置

关卡星级、章节进度、提示余额、每日谜题连胜、教程进度、语言以及音效、音乐和触感设置保存在应用的本地存储中，用于继续游戏和保留您的偏好。开发者不会在服务器上接收这些信息。

您可以在设备设置中清除应用数据，以删除本地信息。卸载应用通常会删除其本地数据。操作系统的备份和恢复服务可能根据您的设备设置及操作系统提供商的政策保留或恢复这些数据。

支持邮件

如果您向我们发送邮件，我们会收到您的邮箱地址、邮件内容以及您自行附加的文件。我们使用这些信息回复并处理您的请求，不用于广告。请勿发送密码或与解决问题无关的信息。

邮件服务提供商和我们的支持邮件转发服务可能会处理您的通信内容。我们会在处理请求和履行适用义务所需的期限内保留支持邮件。您可以通过支持邮箱请求删除通信记录；法律要求保留的信息可能继续保存。

儿童

我们不会通过游戏有意收集儿童的个人信息。如果您认为儿童在支持邮件中提供了个人信息，请联系我们，以便我们审核删除请求。

应用商店、操作系统与本网站

Google Play、App Store 和您的设备操作系统可能独立于游戏开发者，依据各自的政策处理信息。本网站托管于 GitHub Pages。托管服务提供商可能根据 GitHub 隐私声明 处理访问相关的技术信息。我们不会在本网站添加广告或分析跟踪器。

变更与联系

如果我们的数据处理方式发生变化，我们会更新本页面及政策生效日期。若添加广告或分析功能，须在发布该版本前更新本政策和应用商店中的相应声明。

如有隐私问题或数据删除请求，请通过 help.blizzard269@dralias.com 联系 Anonymous Play。
