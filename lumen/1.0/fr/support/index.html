Assistance

Lumen: Lights Out · Développeur: Anonymous Play

Des questions, un bug ou une idée ? Écrivez à help.blizzard269@dralias.com en indiquant le modèle de votre appareil et la version de l’application.

Comment jouer ?

Touchez une case pour l’inverser avec ses voisines selon le motif du niveau. Éteignez toutes les lumières pour résoudre le puzzle.

Que signifient les étoiles ?

Trois étoiles signifient que vous avez résolu le niveau près du nombre idéal de coups (par). Les indices peuvent réduire le maximum d’étoiles pour cette résolution.

Ma progression est-elle sauvegardée ?

Oui, sur votre appareil. Elle est supprimée si vous effacez les données de l’application ou la désinstallez.

Le jeu a-t-il besoin d’Internet ?

Non. Le jeu fonctionne hors ligne, sans publicité ni achats intégrés.
