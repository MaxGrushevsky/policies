# policies

Общие правила — в `../CLAUDE.md`. Все юридические документы игр (политика конфиденциальности,
поддержка, при необходимости условия) и `app-ads.txt` живут только здесь. Сайт статический,
Vercel публикует его из `main`: https://policies-phi-bay.vercel.app/

Подробности — [README.md](README.md) (как добавить игру), [VERSIONS.md](VERSIONS.md) (версии),
[ADMOB_DEPLOYMENT.md](ADMOB_DEPLOYMENT.md) (`app-ads.txt`).

## Устройство

- `<игра>/privacy.html`, `<игра>/support.html` — стабильные многоязычные страницы; каждый язык —
  блок `<article id="<язык>" lang="<язык>">`. Языки: `en ru de es fr pt tr id`, у части игр ещё `zh`.
- `sources/<игра>/` — исходники, которых нет среди живых страниц (новые версии политик, поддержка).
- `versions.json` — какая версия игры какими исходниками описана.
- `<игра>/<версия>/<язык>/` и `<игра>/<версия>/<язык>/support/` — снимки, собираемые
  `node scripts/build-versions.mjs`; `<игра>/<версия>/` — список языков.
  Игры открывают `<URL версии><язык>/` (например `CONFIG.privacyPolicyUrl` в flappy-plane и tower-blocks).
- Слаги: `flappyplane`, `towerblocks`, `numbermatch`, `twirl` (+ `gempop`, `lumen`, `burstgrid`).

## Правила

- Любое изменение текста делается **во всех языках** документа сразу: те же пункты, тот же смысл,
  та же дата. Нельзя оставить язык со старой версией. Если перевод вызывает сомнения — сказать пользователю.
- Готовый снимок `<игра>/<версия>/` не меняется: его URL уже указан в сторе. Изменились практики
  (SDK, реклама, аналитика, данные) — новая версия: исходник, запись в `versions.json`, сборка скриптом.
  `--force` для существующей версии — только по просьбе пользователя.
- Описывай только реальные практики игры: сверяйся с её `package.json`, кодом и `GAME.md`.
  Документы одной игры не трогают другие игры; существующие URL не ломать.
- После новой версии обнови ссылку в игре (`privacyPolicyUrl` / ссылки в UI и в `store/`) — это коммит в репозитории игры.
- Пуш в `main` сразу публикует сайт: пушить только по прямой просьбе. Перед тем как вписывать URL
  в консоль стора, проверь, что страница открывается на живом сайте.
